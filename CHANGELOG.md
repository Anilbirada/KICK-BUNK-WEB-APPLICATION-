# Changelog

All notable changes to the KICK BUNK platform are documented in this file.

## [1.0.0] - 2026-11-18

### Added
- **Cryptographic QR Ordering:** Secure HMAC token generation and validation for table dine-in sessions.
- **Light Luxury Redesign:** Ivory, Champagne Gold, Terracotta, and Espresso design system across all customer and admin interfaces.
- **Kitchen Display System (KDS):** Station routing for Clay Oven Tandoor, Curries, and Continental kitchens with bump bar tracking.
- **Bar Dispense Station:** Real-time peg calculation, milliliter pour tracking, and bottle inventory decanting.
- **Indian 5% GST Engine:** Automated 2.5% CGST + 2.5% SGST calculation with GSTR-3B audit outbox.
- **Render Blueprint (`render.yaml`):** Infrastructure-as-code deployment for PostgreSQL, FastAPI, and Next.js.
- **Automated Test Suite:** 100% passing Pytest test coverage across endpoints, tokens, carts, and taxes.
